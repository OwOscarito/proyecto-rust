# Humboldti

Rust terminal social app inspired in Club Penguin

# Keybinds

| Key     | Action    |
| ------- | --------- |
| w/a/s/d | move      |
| t       | open chat |
| y       | dance     |
| u       | wave      |
| q       | quit      |

# Features

- [x] Multiplayer
- [x] Chat
- [x] Emotes
- [ ] Different rooms
- [ ] Penguin Personalization
- [ ] Penguin data persistence

# Run

## Compiling from source
```sh
git clone https://github.com/OwOscarito/proyecto-rust
cargo build --release
./target/release/humboldti
```
